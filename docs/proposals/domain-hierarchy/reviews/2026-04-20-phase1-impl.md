## Phase 0b 일치성 검증

1,119건 중 Phase 0b perDocRoot와 **1,097 match / 22 mismatch** (98.0%).

22 mismatch는 모두 `tier-redesign-*` 문서 → `tier-redesign-readme` 로 수렴.

- 근거: `tier-redesign-readme`는 Phase 0b output 당시 DB에 없었음(신규 23건 중 하나). 이후 `tier-redesign-00-design` 등이 해당 layout 문서로 `depends_on` 링크를 추가함.
- 알고리즘 수동 검증: `tier-redesign-00-design.depends_on → tier-redesign-readme (tier=layout)` → Q2 규칙에 따라 올바르게 tier-redesign-readme 가 root.

## 발견된 이슈

### 알고리즘 이슈 없음

30개 시뮬 테스트 + Phase 0b fixture 재현, 이상 없음.

### Edge case (테스트로 방어됨)

1. **깨진 target**: primary parent 선정 후 target doc이 없으면 current(self) 반환. pre-existing link이 끊긴 경우 대비.
2. **자기 참조 `a → refines → a`**: visited가 즉시 포착, self 반환.
3. **Cycle `a → b → a`**: visited set이 2-cycle에서 중단, 방문 중인 마지막 노드 반환(결정론적).
4. **Component 부모**: domain tier가 아니면 후보에서 제외되므로 `c1 --refines-> c2` (둘 다 component)는 self-root.
5. **Non-domain link types**: `implements`, `traces_to`, `contains`, `refs` 등은 후보에서 제외.

### 지연된 개선 (Phase 2/3으로 이관)

- **top-root-absorption warning**: 현재 diagnostic 미구현. Phase 2 validator에서 root 분포 집계 후 5% 초과 root를 info diagnostic으로 발행 예정.
- **prefix-match gating / hop distance penalty**: Phase 0b 리뷰의 추가 휴리스틱은 Phase 3(구조적 링크 보완)이 더 적절한 해법. 알고리즘에 추가하지 않음.
- **DB drift 자동 감지**: Phase 0b 스냅샷과의 diff는 수동 검증. 추후 regression fixture를 문서화된 fixture로 고정하는 방안 검토.

## Phase 2 연결

Phase 2 validator 통합 시 import 경로 및 예상 사용 패턴:

```typescript
import {
  deriveAllDomainRoots,
  detectOwnerRootMismatch,
  type DomainRootRegistry,
} from "definition-catalog";

// validateGraph 내부
const roots = deriveAllDomainRoots(registry);

// duplicate-coordinate 검증 확장
for (const [key, entries] of dupGroups) {
  const byRoot = groupBy(entries, e => roots.get(e.id) ?? e.id);
  if (byRoot.size > 1 && allSubgroupsSingleton(byRoot)) {
    // key+domain_root로 분해 가능 → resolved (warning 제거)
  }
}

// owner-root-mismatch info diagnostic
for (const entry of registry.all()) {
  const rootId = roots.get(entry.id)!;
  const verdict = detectOwnerRootMismatch(entry, rootId, registry);
  if (verdict === "mismatch") issues.push({ severity: "warning", type: "owner-root-mismatch", ... });
}

// top-root-absorption
const rootCounts = countBy([...roots.values()]);
for (const [root, count] of rootCounts) {
  if (count / registry.all().length > 0.05) issues.push({ severity: "warning", type: "top-root-absorption", ... });
}
```

- `"owner-root-mismatch"` — info 수준
- `"top-root-absorption"` — info 수준
