## 권고

**신규 추가 (2값 모두).** 기존 7 scope은 구체 도메인 분류용이라 "메타 설계 제안"이 편입될 곳이 없음. 재사용 불가.

- scope: `meta` — 메타 설계 제안 (정규 스펙의 규칙 자체를 재정의 대상으로 삼는 문서)
- aspect: `proposal_design` — 제안 문서 분류자 (RFC/제안 단계)

Phase 1 구현 전에 수정해도 되고, 병행 처리도 가능. Task #11 (Proposals Integration — 22 tier-redesign 문서 좌표 부여) 실행 시 일괄 편집.
