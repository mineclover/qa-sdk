# Browser Layout Inspector — Test Design

- Unit: CSSOM fixture proves each matching comma-list selector is emitted separately.
- Unit: requested computed properties return browser-final values, separate from CSS source candidates.
- Unit: synthetic DOM rects prove viewport, document-scroll, and signed edge-gap semantics.
- Build: the MV3 package bundles the content script with the library and emits `manifest.json` + popup.
- Extension integration: Playwright loads the MV3 extension and verifies background → injected content script → CSS source/final style/geometry response, page-click selection, A→B signed measurement, immediate inline style/hide effect, and exact restore. The isolated test manifest adds loopback-only host access because real `activeTab` is granted only by a browser-action click.
- A→B dimension overlay integration: the contained fixture renders four pointer-transparent, viewport-fixed dimension lines for corresponding left/right/top/bottom corners. Labels retain signed CSS px values, so containment and overlap are distinguishable; clearing either comparison endpoint removes them.
- A→B gap/copy integration: a horizontal or vertical gap appears only when the matching orthogonal projections overlap and the measured edges are actually disjoint. Clicking any dimension label copies its exact text; the integration fixture reads the clipboard to verify both a signed corner value and a positive gap value.
- A→B label interaction integration: hovering a dimension label changes its visual emphasis. Pointer drag applies a persistent viewport-relative offset to that label without moving its measurement line; a subsequent click still copies while a moved drag does not.
- A→B zero/drag emphasis integration: corresponding corners with a zero CSS px delta do not render a line or label. While dragging a remaining label, its own dimension line and end ticks use the active teal highlight, which clears when dropped.
- Work-item selector integration: each normal/A/B element exposes ranked selector candidates. Switching a candidate keeps the selected DOM element intact while updating the Side Panel label and the visible comparison summary/copy string to the chosen selectors.
- Side Panel integration: the live MV3 runtime manifest has `side_panel.default_path`, no action popup, `sidePanel` permission, and the Side Panel API required for action-click behavior. Content-script state pushes keep an open panel synchronized after a page click.
- Ruler integration: an actual mouse down → move → up sequence returns viewport start/end coordinates, absolute width/height, and diagonal distance. It is deliberately independent of the DOM A→B edge-gap tool.
- CSS output integration: the selected grid fixture is projected as a CSS block containing final computed values (including Grid/Flex layout fields), followed by clearly labelled matched source candidates rather than a JSON dump.
- JSON exchange integration: an explicitly formatted `browser-layout-inspector.exchange.v1` artifact contains its export timestamp, page URL, viewport/scroll/DPR context, selected inspection, A→B state, Ruler state, snap and guides. CSS remains the default Side Panel output.
- CSS Inspector unit: source candidates are flattened into individual declarations without claiming cascade-winner provenance; final computed declarations are complete and property-name sorted.
- CSS Inspector extension integration: setting or removing a selected element's inline declaration refreshes the inspector immediately; removal reveals the underlying author cascade and restore returns the pre-extension inline declaration. Invalid property names fail without mutating the page.
- Ruler guide integration: optional 8px snap changes only Ruler points; completing a ruler automatically replaces the four viewport-fixed edge guides, and clear removes both overlay nodes and tab-local guide state.
- Side Panel workspace integration: four visibly separate panels keep measurement/selection, selected-element CSS, bounded DOM hierarchy, and page-style/export controls apart. The page tree returns page nodes (not extension overlay nodes), selecting a node changes the normal inspector target, and stylesheet extraction returns readable CSS plus unavailable-CSSOM diagnostics.
- Measurement core unit: DOM-free CSS-pixel rects and viewport points project signed comparison corners, actual disjoint-axis gaps, Ruler dimensions/angle/guide edges, and a framework-neutral tolerance match result for browser test assertions.
- Current-work integration: normal selection, comparison A/B, and Ruler box remain independent list rows; a row refocuses the CSS Inspector and its adjacent clear action removes only that row (clearing A also clears dependent B).
- Auto-select integration: hover updates the normal selection while the mode stays active; Delete/Backspace applies a reversible `display: none` only in that mode, while Escape exits it and editable controls retain their native keys.
- PNG export acceptance: production uses `activeTab` after the user opens the extension action to capture the visible viewport. Playwright cannot simulate that user grant; its integration check verifies the activeTab permission and `captureVisibleTab` API boundary, while the actual download is a manual acceptance check.
- Deferred browser integration: a second-origin stylesheet fixture verifies the `inaccessibleStylesheets` diagnostic.
