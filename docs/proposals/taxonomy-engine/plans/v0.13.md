# Taxonomy Engine v0.13 구현 계획 — multi-gate decision

> 1 markdown decision 안에 여러 분기점(gate) 지원. v0.12 마커 위 확장.

## 목적 ^purpose

**Goal:** 한 markdown 결정에 N gates 표현. FlowSchema가 단일이 아닌 multi-gate로 변환. 기존 single-gate 호환 유지.

**Architecture:**
- 신규 마커 `^gate:<id> <name>` — 본문 안에서 gate 경계 표시
- 첫 ^gate 전 콘텐츠는 schema 전체(unit.purpose/topic)
- 각 ^gate 이후 콘텐츠(^option/^evidence/^phase/^weight/^depends_on)는 해당 gate 소속
- ^outcome은 schema 전체 (결정 완료 시 최종 한 줄)
- ^gate 마커가 0개면 기존처럼 단일 "decide" gate (backward compat)

**Branch:** main 직진.
