```typescript
function toMarkdown(opts: {
  schema: FlowSchema;
  lifecycle: Lifecycle;
  evidence?: Evidence[];
  outcome?: string;
}): { meta: DecisionMeta; body: string };
```

- [ ] **Step 2: 매핑 (toFlowSchema 역함수)**
  - schema.id → meta.id, schema.unit.topic → meta.subject
  - schema.description (= ^purpose) → 첫 문단 + ` ^purpose`
  - gate.phase (default 아니면) → `^phase:<phase>` 마커
  - gate.weight (default 아니면) → `^weight:<weight>` 마커
  - gate.affects → `^depends_on:<id>:<kind>` 마커 N건
  - gate.branches → `## 옵션\n\n<label> ^option:<id>` 형식
  - evidence (있으면) → `## 증거\n\n<content> ^evidence:<kind> weight=N`
  - outcome (있으면) → `## 결정\n\n<outcome> ^outcome`

- [ ] **Step 3: 테스트** — 라운드트립 (toFlowSchema → toMarkdown → parseDecisionFile → toFlowSchema 결과 동일)
