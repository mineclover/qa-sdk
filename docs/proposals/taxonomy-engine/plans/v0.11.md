# Taxonomy Engine v0.11 구현 계획 — decision-flow 변환 어댑터

> 부채 #6 해소. 옵션 3 (변환 어댑터 — markdown → FlowSchema 한 방향) 채택.

**Goal:** bridge에 `toFlowSchema` 변환 어댑터 + `extractEvidence` + Evidence 타입 통합. CLI `qa-sdk decision analyze` 신규.

**Architecture:** bridge가 decision-flow를 dependency로 추가 (한 방향만). markdown DecisionFile → FlowSchema 1:1 단순 매핑. 분석은 decision-flow 함수 호출. in-memory만.

**Tech Stack:** TypeScript ES2023, tsup dual.

**Branch:** main 직진.

**Spec:** [`../concepts/decision-flow-bridge.md`](../concepts/decision-flow-bridge.md).
