## 의도된 제약

- **annotation은 schema 무관:** `toFlowSchema`는 annotation을 propagate하지 않음. 라운드트립은 `optionAnnotations` 옵션을 caller가 명시적으로 전달해야만 보존.
- **annotation 매칭은 silent:** 매칭 option이 없는 annotation은 폐기 (warning 안 함). 향후 `analyzeAnnotationOrphans` 같은 검증 helper로 별도 노출 가능.
- **block-level body:** annotation의 body는 같은 block 전체 cleanText. 옵션과 같은 block에 두면 body가 합쳐짐 — blank line으로 분리해야 함 (기존 evidence와 동일 제약).
- **SyncPreviewPanel은 합성:** 실제 yaml과 무관한 학습/탐색 용도. EntryIR을 합성하여 6 시나리오 시뮬.
- **DecisionFilePicker는 dev only:** Vite plugin 의존 — production build에서는 fetch가 404. 향후 `/api/decision-list`을 정적 JSON으로 prerender하면 production 지원 가능.

- annotation orphan 검증 — extractMarkers에 reportable warnings 채널 신설 필요.
