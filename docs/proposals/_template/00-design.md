# <Proposal Name> — 설계 개요

## 목적 ^purpose
이 제안이 해결하려는 문제와 목표를 1~3문장으로 요약한다.

## 1. 핵심 원칙 ^defines
제안을 관통하는 2~3개의 기본 철학과 원칙을 명시한다.

## 2. 설계 상세
새로운 축, 구조, 규칙 등 제안의 핵심 내용을 상세히 기술한다.

## 3. 기존 체계와의 관계
