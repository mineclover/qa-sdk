# DKG 성장 나선

## 목적 ^purpose

고정 축 정의 → 운용 → 새 기능 발견 → 새 고정 축 순환의 성장 모델. 매 회전에서 과거를 보존하며 누적적으로 성장한다.

## 나선 단계 ^overview

```
발견(discover)  → 운용에서 반복 패턴 발견
닫힘(close)     → 패턴을 고정 축으로 승격
관측(observe)   → 새 축을 기반으로 관측
새 발견(emerge) → 관측에서 새 패턴 발견 → 다음 회전
```
