# QA-SDK Core System

## 목적 ^purpose

전체 QA-SDK 시스템에서 공통으로 사용되는 핵심 데이터 모델, 공통 상수, 타입 정의를 소유한다. 

## 구성 ^overview

- **Common Types**: URN, Identity, Metadata 기본 타입
- **Domain Constants**: 축(Axis) 정의 및 도메인 상수
- **Shared Utilities**: 공통 데이터 처리 로직
