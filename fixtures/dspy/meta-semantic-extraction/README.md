# Meta-Semantic Extraction DSPy Fixtures

These files are tracked schema and fixture samples for the AI-DLC DSPy harness Phase 1 pilot.

Runtime output belongs under ignored `artifacts/dspy/meta-semantic-system/ExtractionPort/v1/`.

Tracked files in this directory:

- `binding.sample.json` — candidate binding manifest shape.
- `eval-cases.v1.sample.json` — evaluation case set shape and initial 30-case coverage.
- `eval-report.sample.json` — expected evaluation report shape.
- `cost-report.sample.json` — expected cost report shape.

The samples target `meta-semantic-system`'s `ExtractionPort` and must not be treated as active production bindings.
