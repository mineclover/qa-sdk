Node — PipeRole 5종

파이프의 역할(role)에 따라 형태(shape)와 색상이 달라집니다. role은 flow 구조에서 자동 도출됩니다.

Node — Certainty 3종

타입 확실성(certainty)은 테두리 스타일로 표현됩니다. flow에 optional/branch가 포함되면 flexible, 혼합이면 mixed.

Node — Entry · Concern · Folded

진입 마커(▶), concern 배지(최대 4개), 접힌 노드(이중 테두리 stadium) 표현입니다.

Node — Role × Certainty 매트릭스

5가지 role과 3가지 certainty의 15개 조합을 모두 표시합니다.

PipeFlow 29종 레퍼런스

각 flow kind가 어떤 role과 concern을 만드는지, 실제 노드 렌더링과 함께 표시합니다.

Edge — ConnectionKind 8종

연결 종류(kind)에 따라 색상 · 선 스타일 · 마커가 달라집니다.

Port & FacetType

포트 dot은 입력/출력 방향과 facetType별 색상으로, edge는 facetType pill 라벨로 의미를 드러냅니다.

Port Dot 갤러리

input-only / output-only / input+output / typed facetType 색상 4종

FacetType Edge 갤러리

next / event / conditional / fan-out edge에 facetType pill 라벨 적용

PipeConcern 배지 8종

관심사(concern)는 노드 우측에 원형 배지로 표시됩니다. flow 구조에서 자동 추출됩니다.

줌 레벨 비교

동일한 PipeGraph를 group / module / leaf 3단계 줌으로 비교합니다.

실전 패턴 갤러리

실제 사용 패턴에서 각 시각 요소가 어떻게 조합되는지 보여줍니다.
